# UNSPENT feature map

`../features.json` is generated by `featuremap` from `../featuremap.config.json` and
never edited by hand. Each file here declares its ids in a `<!-- covers: -->` line, and
`featuremap check` fails when an id has no recipe or a recipe covers a dead id.

## Preconditions

- Godot 4.7 on PATH; after a pull, `tools/_import.sh`.
- Enough free memory for what you run (`vm_stat`); a full `tools/check.sh` needs ~500 MB.
- Never drive `tools/deploy.sh --prod` to verify anything. It ships.

## Proof rules

- Drive the path a player takes: a real frame, a tour through real input. A test that
  mocks the system under check proves nothing about it.
- A test written to show a bug must go red with the bug in place first.
- An unreachable entry point is reported with its missing precondition, not counted.

## Areas

- [audio](audio.md): Procedural sound and the per-landscape score.
- [game](game.md): The entry scene and the signal bus every package talks through.
- [machines-fight](machines-fight.md): Machines on the land, their disposition, depots, keepers, the fight, targeting, defences and raids.
- [people-story](people-story.md): The player's own body, villagers, fauna, named cast, the story's talks and fragments.
- [platform](platform.md): Saving and loading, dev mode, the tour runner.
- [scenes](scenes.md): The game, the model gallery and the title.
- [slate-ui](slate-ui.md): The hacked tablet and every app on it: map, carrying, making, gear, reads, journal, holding, saves, settings, pause, character.
- [survival-gear](survival-gear.md): Taking from the world, hunger and weather, hazards, tracks, gear and abilities, the economy, crafts, settlements.
- [tools](tools.md): The loop scripts.
- [world-look](world-look.md): The lit world: sky and hour, weather, lights and lamps, landscape grounds, foreground, fliers, holograms, crowns, the view.
- [world-places](world-places.md): Realms and portals, landmarks and caches, regional holds.
- [worldgen](worldgen.md): Growing a world from a seed.

## Entry contract

Each area file has an H1, a one-line summary, a `<!-- covers: ids -->` line, then
`## Sub-features`, `## How to reach it`, `## How to check it`, `## Gotchas`.
