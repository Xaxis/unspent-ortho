# UNSPENT feature map

Contract for the area recipes: `../features.json` is generated by `featuremap` from
`../featuremap.config.json`, never edited by hand. Each file here declares its ids in a
`<!-- covers: -->` line; `featuremap check` fails on an id with no recipe or a recipe
covering a dead id.

## Preconditions

- Godot 4.7 on PATH; after a pull, `tools/_import.sh`.
- Free memory for what you run (`vm_stat`); a full `tools/check.sh` needs ~500 MB.
- Never drive `tools/deploy.sh --prod` to verify anything. It ships.

## Proof rules (every area)

- Static: `godot --headless --path . --import --quit`; tests under `tests/` named for the
  package.
- A recipe proves it when the command exits 0; a tour prints `tour NAME done`; for a shot
  or tour, the frames show the thing named (Read them).
- Drive the path a player takes: a real frame, a tour through real input. A test that
  mocks the system under check proves nothing about it.
- A test written to show a bug must go red with the bug in place first.
- An unreachable entry point is reported with its missing precondition, not counted.
- "Options in its header": the tour file's first lines give its full command.

## Entry contract

Each area file: an H1, a one-line summary, the `<!-- covers: ids -->` line, then
`## Sub-features` (one bullet each: id, entry, the proving command, what to see),
`## How to reach it`, `## How to check it`, `## Gotchas`.
